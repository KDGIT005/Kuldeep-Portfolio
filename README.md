## ✨ Features

- **Terminal boot animation** — custom loading sequence with ASCII art

- **Framer Motion animations** — smooth transitions and scroll reveals

## 🚀 Getting Started

### Prerequisites

- [Bun](https://bun.sh/) (preferred) or Node.js 18+

### Local Development

```bash
# Clone the repo
git clone https://github.com/KDGIT005/Kuldeep-Portfolio.git
cd Kuldeep-Portfolio

# Install dependencies
bun install

# Start dev server
bun run dev
```

App runs at `http://localhost:5173`

### Build for Production

```bash
bun run build
```

### Deploy to Cloudflare Workers

```bash
# Install Wrangler CLI (if not already)
bun add -g wrangler

# Authenticate
wrangler login

# Deploy
wrangler deploy
```
